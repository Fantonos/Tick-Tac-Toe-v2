# Tick-Tac-Toe-v2
Version 2 of my original Tick-Tac-Toe Repo, this is a simple Tic-Tac-Toe game implemented in Python using Pygame. The game supports two modes: Player vs Player and Player vs Bot.

Orginal Repo [Here](https://github.com/Fantonos/Tick-Tac-Toe)

### Installation
1. Download the latest release from the [Releases](https://github.com/Fantonos/Tick-Tac-Toe-v2/releases) section.
2. Extract the downloaded file.
3. Locate the `.exe` file in the extracted folder.
4. Double-click the `.exe` file to start the application.
5. Follow the on-screen instructions to navigate through the features.

## Features

- Two game modes: Player vs Player and Player vs Bot
- Randomized bot moves
- Details section for game instructions
- Win condition checking

## Python Requirements

- Python 3.x
- pygame 2.6.0
